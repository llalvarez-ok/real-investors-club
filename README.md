# Real Investors Club

Plan, guiones y producción del canal de YouTube [@REALinvestorsc](https://www.youtube.com/@REALinvestorsc).

- `CLAUDE.md`: reglas y estado del proyecto.
- `docs/prompt-maestro.md`: el prompt original de producción.
- `contenido/`: programa F.O.C.U.S. (currículum y lecturas de los 6 niveles).
- `youtube/`: títulos, descripciones y etiquetas por lección.
- `diseno/`: esquema y generador de láminas.
- `marca/`: logos oficiales.
- `guiones/`: guiones de las lecciones.
- `herramientas/`: scripts del proyecto.
- `analisis/`: diagnósticos del canal con fecha.
