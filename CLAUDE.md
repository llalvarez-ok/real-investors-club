# Proyecto: canal de YouTube "Real Investors Club" (RIC)

Canal en español sobre educación financiera, trading (stocks, forex, crypto) y psicotrading. Handle: @REALinvestorsc, creado el 19/04/2026. Web: http://www.realinvestors.club. El usuario habla español rioplatense (voseo).

Este proyecto es independiente del canal Atajos IA: no mezclar contenido, credenciales ni herramientas entre ambos.

- Contenido central: el programa F.O.C.U.S. El Nivel 0 "DESPERTAR" (gratis, 18 lecciones, con examen y certificado en la web) tiene tres pilares: finanzas personales, técnica y psicología del inversor.
- Las lecciones del Nivel 0 se publican en la playlist "Nivel 0 - Metodo F.O.C.U.S.".
- Temas de finanzas: nunca prometer rentabilidad, incluir siempre el aviso de que no es asesoramiento financiero y aclarar el riesgo.
- Persona gramatical: pendiente de definir (hoy el canal mezcla voseo y "tú").
- Análisis del canal en `analisis/`.
